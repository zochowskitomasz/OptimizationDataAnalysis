# OptimizationDataAnalysis

In this project, we analyze two algorithms used for large transformer model training and compare them to known optimizers. Furthermore, we check the importance of using burn-in and warmup techniques for gradient stabilization during the initial phase of training. We expand on the original authors’ paper by evaluating performance of these methods for a smaller transformer model.

Original paper: [High-probability Bounds for Non-Convex Stochastic Optimization with Heavy Tails](https://arxiv.org/abs/2106.14343)

Project report: [Optimization in Data Analysis Project Report](https://github.com/zochowskitomasz/OptimizationDataAnalysis/blob/main/OIDA_Report.pdf)

This project was completed by Piotr Jurczyk, Jan Wyrzykowski and Tomasz Żochowski as a part of **Optimization in Data Analysis** classes at Warsaw University of Technology.
